The `v=29` follow-up supersedes the asset version above. A file selection now creates one path/group/PR/snapshot-bound scroll request, consumed only after an accepted diff render. Honest product assessment: useful as a local PR-discovery/comparison workspace and revision-bound decision history, but not yet demonstrated as a reliable end-to-end triage workflow. In the read-only snapshot inspected for this assessment, 2,319 PRs form 1,831 groups: 1,606 singleton groups and 225 multi-PR groups containing 713 PRs, with 189 hotspot files. That is about 21% fewer navigation units, not evidence of 21% less review time. Grouping is based on file overlap rather than equivalent intent or correctness; related ranking has synthetic regression cases but no representative maintainer-quality measurement. Local approval is neither GitHub approval nor proof that the reviewer examined every member. The recent Host/diff/scroll failures demonstrate that the existing focused tests did not sufficiently validate the main user journey.

The next product priorities should be a reliably validated inspect → compare → decide → resume workflow, more useful per-PR outcomes (including recording which competing PR to keep and why), and a small maintainer-led trial against the normal review workflow. Measure completed decisions, mistaken associations, and time before claiming productivity gains. These are recommendations, not additional implementation in this scroll-repair scope.

## Cross-cutting simplification and performance

The active pipeline now uses deterministic file-set buckets and indexed candidates. Retired runtime modules for dense TF-IDF embeddings, graph generation, MinHash/LSH, and SimHash were removed. Pipeline results no longer allocate dummy vectors or eager dense overlap matrices; exact overlap/patch detail is derived lazily in bounded pages.

The reproducible 2,200-PR synthetic corpus retained membership SHA-256 `51a49276acbb025566df94ead3538611b8d9aaaa0dba9ee473526fcd661908dd`. The historical baseline was `0.843325666` seconds; release-candidate local samples were approximately `0.10–0.11` seconds. The adversarial 2,200-PR shared-path corpus produced 2,200 singleton groups with zero Jaccard candidate checks. These are synthetic single-machine measurements, not the historical live corpus.
